# 🌸 Visualizing Hanzi & Kanji: Digital Humanities Project

¡Hola! Este repositorio contiene una colección de tarjetas e ideogramas (汉字 / 漢字) construidos vectorialmente con **SVG** y animados con **CSS puro** y *checkbox trick* para interactividad sin JS.

## 📌 Sobre el proyecto

Este proyecto nace de mi pasatiempo de escribir en **Substack**, combinando el aprendizaje de idiomas con la exploración de las **Humanidades Digitales**. 

La idea principal es crear una herramienta didáctica e interactiva para acompañar mis artículos, donde los lectores puedan:
- Visualizar el orden y dirección exactos de los trazos (*stroke order*).
- Distinguir de forma intuitiva los trazos gracias a la paleta de color inspirada en el concepto de *Sakura Branch & Matcha Honey*.
- Rebobinar y reiniciar la animación con un solo clic sobre la tarjeta.

## 🛠️ Tecnologías utilizadas

- **HTML5 & SVG:** Definición manual de trazos y elementos vectoriales (`<path>`, `<g>`).
- **CSS3:** Animaciones con `@keyframes`, sintaxis de sincronización por clase y control interactivo con pseudo-clases (`:checked`).
- **Google Fonts:** Tipografías serif para una estética editorial.
